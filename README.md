# Daynua

날짜 중심의 가벼운 할 일 달력. 무엇을 할지뿐 아니라 **무엇을 했는지**를 남긴다.

- 월에서는 계획하고, 주에서는 한 주를 정리하고, 년에서는 지나온 시간을 돌아본다
- 빌드 도구 없음 · npm 의존성 없음 — `index.html` 하나로 돌아간다
- 설치형(PWA) · 오프라인 동작 · 기기 간 실시간 동기화(Supabase)

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (HTML·CSS·JS) |
| `sw.js` | 서비스 워커 — 오프라인, 알림 |
| `manifest.json` | 설치 정보 |
| `widget.html` · `widget.txt` | 아이폰 위젯(Scriptable) 설치 안내와 스크립트 |
| `privacy.html` | 개인정보처리방침 |

## 자체 점검

주소 끝에 `#test` 를 붙이고 열면 콘솔에서 날짜 계산·이월·검색·색 대비 검사가 돌아간다.
